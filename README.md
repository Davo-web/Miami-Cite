# Miami Condo Kings — сайт агентства недвижимости


## Описание

Сайт представляет собой веб‑приложение для агентства недвижимости Miami Condo Kings. Он содержит информацию о компании, галерею объектов недвижимости, отзывы клиентов, а также форму для связи.

## Функционал

- **Главное меню** (бургер‑меню): позволяет перейти к разным разделам сайта (о компании, галерея, отзывы, контакты).
- **Галерея объектов**: демонстрация фотографий и краткой информации о различных объектах недвижимости. Есть кнопки для показа/скрытия дополнительных фотографий.
- **Отзывы клиентов**: блок с отзывами трёх клиентов, включая их фото, должность и текст отзыва.
- **Форма обратной связи**: позволяет отправить запрос с указанием имени, email и сообщения. При отправке проверяется валидность данных, и в случае успеха отображается модальное окно с подтверждением.
- **Кнопка «Вернуться наверх»**: появляется при прокрутке страницы вниз и позволяет плавно вернуться к началу страницы.
- **Адаптивность**: сайт корректно отображается на разных устройствах (ПК, планшеты, смартфоны) благодаря медиа‑запросам в CSS.


## Структура проекта


Проект состоит из трёх основных файлов:
- `index.html` — HTML‑разметка сайта.
- `style.css` — стили CSS, отвечающие за визуальное оформление.
- `script.js` — JavaScript‑код, реализующий интерактивные элементы.


Также присутствуют изображения, размещённые в папке `img`.


## Технологии

- **HTML5** — разметка веб‑страницы.
- **CSS3** — стилизацию и адаптивный дизайн.
- **JavaScript** — интерактивность и обработку событий.

- **Google Fonts** (Roboto) — подключение внешнего шрифта для единообразного отображения текста.


## Как запустить проект


1. Скачайте все файлы проекта (HTML, CSS, JS и папку `img`).
2. Откройте файл `index.html` в любом современном браузере (Chrome, Firefox, Safari, Edge и т. п.).
3. Сайт будет доступен локально на вашем устройстве.


## Особенности реализации


- **Бургер‑меню**: при клике на иконку бургер‑меню открывается боковое меню с навигацией. Закрывается по клику на пункты меню, по клавише Esc.
- **Валидация формы**: перед отправкой проверяются поля «Имя», «Email» и «Сообщение». Если какое‑то поле не заполнено или email некорректен, выводится сообщение об ошибке.
- **Модальное окно**: после успешной отправки формы появляется модальное окно с сообщением «Form has been successfully submitted!». При клике на кнопку «Ok» окно закрывается.
- **Плавная прокрутка**: используется `scroll-behavior: smooth` для плавного перехода при клике по якорям.
- **Доступность**: добавлены атрибуты `alt` для изображений, семантические элементы HTML, корректные заголовки и подписи.
